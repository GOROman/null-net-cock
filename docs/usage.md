# 使い方

## 設定ファイル

`null-net-cock.conf.example` を参照してください。`キー = 値` の形で書き、`#` 以降はコメントです。

| キー | 意味 | 既定値 |
|---|---|---|
| `bbs_name` | ログに出す名前 | `NULL-NET` |
| `net_id` | ネットワーク ID (初回起動時だけ使う) | `TEST` |
| `listen` | TCP の待ち受け | `0.0.0.0:6868` |
| `ws_listen` | WebSocket の待ち受け (下の「WebSocket 回線」) | なし (使わない) |
| `ws_code` | WebSocket の回線の文字コード | `utf8` |
| `data_dir` | データの置き場所 | `data` |
| `max_lines` | 回線数 (最大 128) | `16` |
| `idle_timeout` | 無操作で切断するまでの秒数 | `300` |
| `session_minutes` / `guest_minutes` | 持ち時間の既定値 (分) | `60` / `15` |
| `default_code` | 端末の文字コード `sjis` / `utf8` | `sjis` |
| `mes_file` | NET-COCK の `MES.TXT` | なし (内蔵の文言) |
| `mes_esc_file` | NET-COCK の `MES_ESC.TXT` (MODE で ESC を使うと答えた会員に出す) | なし |
| `sysmes_file` | NET-COCK の `SYS_MES.DAT` (初回起動時に取り込む) | なし |
| `help_file` | NET-COCK の `HELP.TXT` (表示のテンプレート。旧版の 6 ブロックのものも読める) | なし (内蔵のテンプレート) |
| `console` | ホストコンソールを使うか (`on` / `off`。標準入力が端末のときだけ動く) | `on` |
| `host_access` | ホストコンソールでログインするときに打つ文字列 | `cock` |
| `modem<回線>.<項目>` | モデム回線 (下の「モデム回線」) | なし |

## モデム回線

シリアル (USB-UART など) につないだモデムで着信を受けられます。設定ファイルに `modem<回線番号>.<項目>` の形で書きます (`null-net-cock.conf.example` を参照)。

```
modem1.path = /dev/cu.usbserial-XXXX
modem1.baud = 9600
modem1.init = ATZ; ATE0V1Q0X4&C1&D2S0=0
modem1.code = sjis
```

- 起動すると初期化コマンドを 1 つずつ送って `OK` を待ち、着信を待ちます
- `RING` が `rings` 回来たら `ATA` で応答し、`CONNECT` の後ろの速度 (例 `2400/V42BIS`) を LOG に残します
- キャリア断は DCD と、受信した `NO CARRIER` の両方で見ます (DCD の配線が無いケーブルは `carrier = text`)
- セッションが終わると DTR を落として切り (`hangup = escape` なら `+++` と `ATH0`)、初期化からやり直します
- モデムの取りこぼしを避けるため、OK の後は 200ms (ATZ / AT&F の後は 1 秒)、RING の後は 300ms 待ってから次を送ります。ATA の後にまた RING が来たら ATA を送り直します
- モデムに割り当てた回線番号は TCP の接続には使いません
- AT コマンドのやり取りはシステムログ (`data/system.log`) に残ります

## WebSocket 回線

ブラウザのソフトウェアモデム [null-modem](https://github.com/GOROman/null-modem) などから WebSocket でつなげます。`ws_listen` に待ち受けを書き、Cloudflare Tunnel などで `wss://` として公開します。

```
ws_listen = 127.0.0.1:6869
```

```sh
cloudflared tunnel --url http://localhost:6869
```

- telnet の処理はせず、受け取ったバイトをそのまま回線の入力にします (XMODEM / YMODEM も通ります)
- LOG の速度は `WS`。接続元は中継が付けた `CF-Connecting-IP` (無ければ `X-Forwarded-For`) を使います
- 回線番号は TCP と同じところから取ります

## ログイン

- `ID:` には ID 番号 (`10`)、ネットワーク ID 付き (`TEST0010`)、ログネームのどれでも入れられます
- `GUEST` か `0` でゲストとしてログインします
- 入会の方式が「自動」(既定) のとき、ゲストには ID を取るか聞きます。申し込み項目を入れるとその場で仮 ID が発行されます
- 初めてログインした会員は、公開情報 (住所・職業・機種・生年月日・性別・ログネームなど) を登録します
- パスワードを 3 回間違えると切断します
- 回線ごとのアクセスレベル (LINESET) より低い会員と、AOFF 中の一般会員はログインできません
- 同じ ID で 2 つの回線に同時にログインすることはできません

## コマンド

コマンドは省略できます。先頭から一致した最初のものが選ばれます (例: `B` は `BREAD`、`BW` は `BWRITE`)。
`\インデックス` と入力すると、そのボードを直接読みます。`?` で使えるコマンドの一覧が出ます。

### メニュー方式

`MODE` でメニュー方式にすると、番号で選べるようになります。メインメニューは 1 会員データ / 2 ボード / 3 メール / 4 システムの設定 / 5 ボードの設定 / 6 チャット / 7 入会・登録 / 8 メンテナンス / 9 回線を切る で、各メニューの `0` で戻ります。自分のレベルで使えないものは出ません。
「毎回メニューを出す」にしないときは、`?` でメニューを出し直せます。メニュー方式でもコマンド名は入力できます (`\インデックス` は使えません)。

### ボードを読んでいるとき (`Command` の問い)

ボードを開くと、未読のうち一番古いメッセージのヘッダ (番号・日時・タイトル・発信者) を出して止まります。

| キー | 内容 |
|---|---|
| Enter / `R` | 今のメッセージの本文を読んで、次へ進む |
| `V` | 最新まで続けて読む (RALL の途中なら、以後は止まらずに読む) |
| `A` / `L` | タイトルを 20 件並べる (発信者を名前で / ID で)。位置も 20 件進む |
| `N` / `B` | 次 / 前のメッセージへ |
| `T` / `E` | 一番古い / 一番新しいメッセージへ |
| 番号 | その番号へ |
| `P` / `F` | 今のメッセージ / 直前に読んだメッセージにリプライ |
| `W` | このボードに書く |
| `D` | 削除 (自分のもの。リプライが付いたものは消せない) |
| `M` / `O` | 読まれた回数 (プログラムはダウンロード回数も) / ボードオペ |
| `U` / `I` | リプライ先へ / 元の位置へ戻る |
| `X` / `Y` | XMODEM / YMODEM で受け取る (プログラムボード) |
| `S` | バッチリストに加える (プログラムボード) |
| `!` | メッセージの編集 (ボードオペ・SYSOP。d:削除 t:タイトル u:発信者 f:ファイル名 s:サイズを直す) |
| `Q` | 終わる |

メールボード (MREAD) も同じ操作で、1 通読むごとに削除するかを聞きます。

### 書き込み

タイトル、本文の順に入力します。本文は `.` だけの行で終わり、`書き込みますか` の問いに次のどれかで答えます。

| キー | 内容 |
|---|---|
| `Y` | 書き込む (プログラムボードでは、ここでファイルを受け取る) |
| `N` | 捨てる |
| `T` | タイトルを変える |
| `E` | 本文を最初から入れ直す |
| `C` | 入力した文章を表示する |
| `Q` | 書きかけのまま抜ける (次に同じボードに書くときに続きから書ける) |

### チャット

`chat:` のあとに 1 行 (150 文字まで) 入れると、チャットを受け付けている回線に `(名前)発言` の形で流れます。
チャットの発言やログイン・ログアウトの知らせは、CHAT の中にいなくても (チャットを受け付けていれば)、入力の途中に割り込んで表示します。

| 入力 | 別の書き方 | 内容 |
|---|---|---|
| `.S[回線]` | | 指定した回線 (省略時は全部) との送受信を ON。`.S125` や `.S1,12` |
| `.O[回線]` | | 送受信を OFF |
| `.R[回線]` | | 受信だけ ON |
| `.C` | | シスオペを呼ぶ (CMODE のレベルより低い人や、CMODE が OFF のときは断る) |
| `.T文` / `.B文` | 先頭 `＊` / `／` | 右寄せ / 中央寄せ (80 桁基準) |
| `.X` | | 設定 (ESC で色を付ける / エコー / 自分の発言を表示 / 名前か ID で表示) |
| `.Pn文` | `－ｎ文` | 回線 n だけに送る |
| `.U回線` / `.A文` | `＝文` | ローカル送出先を登録 / そこにだけ送る |
| `.L` | `*` `＊` だけの行 | 回線の一覧 |
| `.Q` / `.` / `Q` | | 抜ける |

CTIME で禁止した時間帯は、対象の回線でチャットできません。

### プログラムボードとファイル転送

BMAKE でボードの種類を `program` にすると、1 件ごとにファイルを 1 つ付けられます。

- **上げる**: 書き込みの `Y` のあと、方式 (YMODEM / YMODEM-g / XMODEM-CRC / XMODEM-SUM) を選んで、端末ソフトから送ります。
  XMODEM のときはファイル名を入力します。受け取りに失敗したときは文章が残るので、もう一度 `Y` で送り直せます
- **下ろす**: 読んでいるときに `X` (XMODEM。ブロックを 1024 か 128 から選ぶ) か `Y` (YMODEM)
- **まとめて下ろす**: `S` でバッチリストに加え (16 件まで)、コマンド `BATCH` で YMODEM でまとめて送ります。
  BATCH の中では `Y` 送る / `O` 送ってから回線を切る / `N` 抜ける / `D` 外す / `L` 一覧 / `C` 空にする
- 中止は Ctrl-X を数回。telnet の BINARY オプションを使うので、0xFF や CR を含むファイルもそのまま送れます
- ファイルはデータベース (`files` 表) に入ります。1 つ 8MB まで

### SYSOP

| コマンド | 内容 |
|---|---|
| `BMAKE` / `BCHANGE` / `BKILL` | ボードの作成 / 設定の変更 (Enter は今の値のまま) / 削除 |
| `BTITLE` / `BUSER` | タイトルの変更 / CUG ボードのアクセス権 (a:読み書き r:読むだけ w:書くだけ n:なし)。ボードオペも使える |
| `MAKEID` | 入会の申し込みに ID を発行する (y:新しい番号 n:発行しない o:削除した番号を使い回す s:フリガナで探す q:やめる) |
| `GULV` | 仮会員を 1 人ずつ正会員にする (y / n / d:削除 / s / q) |
| `ULEVEL` / `UTIME` | 会員のレベル / 1 日の持ち時間 (今の L と T を出す) |
| `UPASS` | 会員のパスワードを見て、ログネームとパスワードを入れ直す |
| `MCHANGE` | 会員管理者を別の ID (レベル 100 以上) に移す |
| `IDKILL` / `IDCOPY` / `IDSET` | ID の削除 (書き込みとログも消す) / 複写 (書き込みとログの ID も書き換える) / 状態フラグ |
| `UDLIST` / `UDEDIT` | 会員データを CSV で出す / 条件で探して 1 件ずつ直す (項目番号は下の表) |
| `LCSET` | ログインコール (その会員がログインしたら SYSOP に知らせる。M:次に止めるまで B:消すまで C:消す) |
| `MESEDIT` | ログイン画面などのメッセージ (0〜9) を変える |
| `SYSSET` | ネットワーク ID、レベル、持ち時間、メールの大きさ、総ボードサイズ、総 PDS サイズ、会員管理者 |
| `SIGNUP` / `IMODE` | 入会の方式 (自動 / 手作業 / オンラインでは受け付けない) / 新しい ID の初期モード |
| `LINESET` | 回線ごとのアクセスレベルと時間のモード (ノーマル / タイムアウトなし / 常時タイムカウント) |
| `CTIME` | チャット (と時間制限付きのボード) を使えない曜日・時間と、その対象の回線 |
| `CMODE` | チャットコールを受けるレベル (N:0 L:30 M:40 H:80 S:100 O:OFF) |
| `SCSET` / `SCLIST` | スケジュールの登録 / 一覧と削除 (期間型はオープニングに、スポット型はその時刻に全回線へ。システムダウンも付けられる) |
| `SDTIME` | 1 / 3 / 5 分後にデータを保存して止める (0 で解除)。その間は新しいログインを禁止し、30 秒ごとに残りを知らせる |
| `AOFF` / `AON` | 新しいログインを禁止 / 許可 (禁止中はログイン中の全員の時間を数える) |
| `SECRET` / `SECOFF` | 極秘モード (LLIST に出ない。ログアウトしても LOG に残さず、ほかの回線に知らせない) |
| `LBUSY` | BUSY 時間 (対象の回線が全部埋まっている時間) を数える回線 |
| `FILEM` | ファイルメンテナンス (削除したものと保存数を超えたものを外し、番号を詰める) |
| `HFCONT` | ファイル管理 (下の「HFCONT」) |
| `REPORT` | 稼働状況 (申し込み数、ID 数、タイトル数、容量、ディスクの空き、メモリ、入会の方式など) |
| `KEYLOCK` | ホストコンソールのキーボードロックを外す |

### HFCONT

データディレクトリの `files/` の中だけを扱うファイル管理です。そこから外には出られません。

| 入力 | 内容 |
|---|---|
| `L` | 一覧 (印を付けたものに `*`) |
| `C 名前` / `C ..` | ディレクトリに入る / 上に戻る |
| `K 名前` | ディレクトリを作る |
| `D 名前` | 削除 (確認あり) |
| `R 旧 新` | 名前を変える |
| `P 名前 先` | 複写 (先がディレクトリならその中へ) |
| `S 名前` / `E 名前` / `M` | 印を付ける / 外す / 印の一覧 |
| `Y` / `X` | 今のディレクトリに YMODEM / XMODEM で受け取る |
| `G` | 印を付けたファイルを YMODEM でまとめて送る |
| `Q` | 終わる |

## 持ち時間

- 会員ごとに 1 日の持ち時間があり、ゲストは「最低持ち時間」(SYSSET) です。1 日分を使い切った会員も、最低持ち時間ぶんは使えます
- 時間を数えるかどうかは回線のモード (LINESET) で決まります
  - **ノーマル**: 普段は数えません。ノーマルの回線が全部埋まったら、一番早くログインした人から数え始めます
  - **タイムアウトなし**: 数えません
  - **常時タイムカウント**: いつも数えます
  - AOFF の間は全員を数えます。SYSOP (レベル 100 以上) は数えません
- 残りが 60 秒になると予告し、0 になると切断します。本日の残りは、数えた時間だけ減ります
- 無操作が `idle_timeout` 秒続いたときも切断します (ホストコンソールは除く)

## ホストコンソール (0 回線)

起動した端末 (標準入力が端末のとき) に `host>` が出て、コマンドで操作できます。X68000 版のファンクションキーの代わりです。

| コマンド | 内容 |
|---|---|
| `cock` | ホストからログインする (0 回線。無操作で切れない。文字列は `host_access` で変えられる) |
| `lines` | 回線の一覧 |
| `mon N` | N 回線目の画面を監視する (Enter で終わる) |
| `op N` | 監視しながら代わりに入力する (`~.` だけの行で終わる) |
| `kick N` | N 回線目を切る |
| `bcast 文` | 全回線に知らせる |
| `lock` | キーボードロック (外すのは外線からの `KEYLOCK`) |
| `call` | チャットコールのモードを順に切り替える (ON / ON L / ON M / ON H / ON S / OFF) |
| `quit` | 保存して終了する (誰もログインしていないときだけ) |

メール・会員データのコマンド (MREAD / MWRITE / UREAD / UDLIST など) の最中は、監視しても画面を見せません。Shift_JIS の回線も UTF-8 にして見せます。

## HELP.TXT (表示のテンプレート)

ボードの見出し、メッセージのヘッダ、オープニング、ログアウト、UREAD、USTAT、ACCESS の表示と、各モードのヘルプ、入会の案内は、テンプレートから作ります。
`help_file` に NET-COCK の HELP.TXT を指定すると元と同じ表示になり、指定しないときは内蔵のテンプレートを使います。

ブロックの並び (コメント行 `*` で区切る。`!!` で終わり):
0 ボードの見出し / 1 リプライ先 / 2 メッセージのヘッダ / 3 ゲストのオープニング / 4 会員のオープニング / 5 ログアウト / 6 UREAD / 7 USTAT / 8 ACCESS /
9 チャットのヘルプ / 10 書き込みのヘルプ / 11 読み出しのヘルプ / 12 バッチのヘルプ / 13 自動発行の案内 / 14 手作業発行の案内。
6 ブロックだけのファイル (旧版) は 9〜14 として読みます。

マクロは `/c` (長い形: 桁を揃える、4 桁の年、ゼロ詰めの ID、時:分:秒) と `%c` (短い形: 詰めない、2 桁の年、時:分、秒数、レベルは名前) です。
主なもの: `/"` ボード名 `/#` タイトル `/&` `/'` 日付・時刻 `/)` `/*` 発信者の ID・名前 `/-` インデックス (`%-` は小文字) `/\` `/[` 位置・総数 `/_` バイト数
`/0`〜`/9` システムメッセージ `/?` ログネーム `/S` ID `/B` `/C` 前回のログイン `/H` 今回の時間 `/N` ログイン回数 `/K` レベル `/>` 新着メール `/|` スケジュール `/=` チャットの状態 `/aN`〜`/hN` 回線の統計。
条件: `/X` リプライ `/Y` メール `/Z` プログラム `/}` ルート `/u` 仮会員 `/v` 一般 `/w` Sigop `/x` Sysop `/y` 会員管理者 `/z` パスワードミスがあった。
`/c` は真のとき、`%c` は偽のときに `%%` までを出します (並べると AND)。`/m` 以後の会員データは UREAD の相手のもの。`%/` で改行せずに終わり、`//` は `/`、`/%` は `%`。

## 終了

SIGTERM / SIGINT (Ctrl-C) / SIGHUP を受けたとき、SDTIME・スケジュールのシステムダウンのとき、ホストコンソールの `quit` のときは、データを保存してから終了します。

# 使い方

## 設定ファイル

`null-net-cock.conf.example` を参照してください。`キー = 値` の形で書き、`#` 以降はコメントです。

| キー | 意味 | 既定値 |
|---|---|---|
| `bbs_name` | ログに出す名前 | `NULL-NET` |
| `net_id` | ネットワーク ID (初回起動時だけ使う) | `TEST` |
| `listen` | TCP の待ち受け | `0.0.0.0:6868` |
| `data_dir` | データの置き場所 | `data` |
| `max_lines` | 回線数 (最大 128) | `16` |
| `idle_timeout` | 無操作で切断するまでの秒数 | `300` |
| `session_minutes` / `guest_minutes` | 持ち時間の既定値 (分) | `60` / `15` |
| `default_code` | 端末の文字コード `sjis` / `utf8` | `sjis` |
| `mes_file` | NET-COCK の `MES.TXT` | なし (内蔵の文言) |
| `sysmes_file` | NET-COCK の `SYS_MES.DAT` (初回起動時に取り込む) | なし |

## モデム回線

シリアル (USB-UART など) につないだモデムで着信を受けられます。設定ファイルに `modem<回線番号>.<項目>` の形で書きます (`null-net-cock.conf.example` を参照)。

```
modem1.path = /dev/cu.usbserial-XXXX
modem1.baud = 9600
modem1.init = ATZ; ATE0V1Q0X4&C1&D2S0=0
modem1.code = sjis
```

- 起動すると初期化コマンドを 1 つずつ送って `OK` を待ち、着信を待ちます
- `RING` が `rings` 回来たら `ATA` で応答し、`CONNECT` の後ろの速度 (例 `2400/V42BIS`) を LOG に残します
- キャリア断は DCD と、受信した `NO CARRIER` の両方で見ます (DCD の配線が無いケーブルは `carrier = text`)
- セッションが終わると DTR を落として切り (`hangup = escape` なら `+++` と `ATH0`)、初期化からやり直します
- モデムの取りこぼしを避けるため、OK の後は 200ms (ATZ / AT&F の後は 1 秒)、RING の後は 300ms 待ってから次を送ります。ATA の後にまた RING が来たら ATA を送り直します
- モデムに割り当てた回線番号は TCP の接続には使いません
- AT コマンドのやり取りはシステムログ (`data/system.log`) に残ります

## ログイン

- `ID:` には ID 番号 (`10`)、ネットワーク ID 付き (`TEST0010`)、ログネームのどれでも入れられます
- `GUEST` か `0` でゲストとしてログインします
- 入会の方式が「自動」(既定) のとき、ゲストには ID を取るか聞きます。申し込み項目を入れるとその場で仮 ID が発行されます
- 初めてログインした会員は、公開情報 (住所・職業・機種・生年月日・性別・ログネームなど) を登録します
- パスワードを 3 回間違えると切断します
- 持ち時間を過ぎると切断します (SYSOP は無制限)

## コマンド

コマンドは省略できます。先頭から一致した最初のものが選ばれます (例: `B` は `BREAD`、`BW` は `BWRITE`)。
`\インデックス` と入力すると、そのボードを直接読みます。`?` で使えるコマンドの一覧が出ます。

### 一般

| コマンド | 内容 |
|---|---|
| `OFF` | 回線を切る |
| `BREAD [ボード]` | ボードを読む |
| `BWRITE [ボード]` | ボードに書く |
| `RALL` / `RNALL` | 巡回対象のボード (メールも含む) の未読を読む (RNALL は止まらずに表示) |
| `BSET` | 読めるボードを順に出すので、巡回の対象にするかを Y/N で答える (Enter は今のまま、Q で終わり) |
| `BATCH` | バッチリストのファイルを YMODEM でまとめて受け取る |
| `PMOVE` | 全ボードの既読位置を動かす (t:先頭 e:最新 l:前回のログイン d:日時を指定) |
| `MREAD` / `MWRITE` | メールを読む / 出す (宛先は 4 人まで) |
| `MCHECK` | 自分が出したメールが読まれたかを見る (宛先ごとに (n) 未読 (r) 既読 (d) 削除) |
| `MBSET` | メールボックスを閉じる・開く |
| `CHAT [回線 [文]]` | チャット。回線番号を付けるとその回線に電報を送る |
| `COFF` / `CON` | チャットを受け付けない / 受け付ける |
| `LLIST` | 回線の使用状況 |
| `LOG` | ログインの記録 |
| `IDLIST` / `NEWMEM` | 会員の一覧 / 新しい会員 |
| `UREAD [ID]` / `UWRITE` | 会員の情報を見る / 自分の情報を変える |
| `USTAT` | 自分の利用状況 |
| `MODE` / `PASS` | 動作の設定 / パスワードの変更 |
| `JOIN` | 入会の申し込み |
| `CLS` / `VERSION` | 画面の初期化 / 版数 |

### ボードを読んでいるとき (`Command` の問い)

ボードを開くと、未読のうち一番古いメッセージのヘッダ (番号・日時・タイトル・発信者) を出して止まります。

| キー | 内容 |
|---|---|
| Enter / `R` | 今のメッセージの本文を読んで、次へ進む |
| `V` | 最新まで続けて読む (RALL の途中なら、以後は止まらずに読む) |
| `A` / `L` | タイトルを 20 件並べる (発信者を名前で / ID で)。位置も 20 件進む |
| `N` / `B` | 次 / 前のメッセージへ |
| `T` / `E` | 一番古い / 一番新しいメッセージへ |
| 番号 | その番号へ |
| `P` / `F` | 今のメッセージ / 直前に読んだメッセージにリプライ |
| `W` | このボードに書く |
| `D` | 削除 (自分のもの。リプライが付いたものは消せない) |
| `M` / `O` | 読まれた回数 (プログラムはダウンロード回数も) / ボードオペ |
| `U` / `I` | リプライ先へ / 元の位置へ戻る |
| `X` / `Y` | XMODEM / YMODEM で受け取る (プログラムボード) |
| `S` | バッチリストに加える (プログラムボード) |
| `!` | メッセージの編集 (ボードオペ・SYSOP。d:削除 t:タイトル u:発信者 f:ファイル名 s:サイズを直す) |
| `Q` | 終わる |

メールボード (MREAD) も同じ操作で、1 通読むごとに削除するかを聞きます。

### 書き込み

タイトル、本文の順に入力します。本文は `.` だけの行で終わり、`書き込みますか` の問いに次のどれかで答えます。

| キー | 内容 |
|---|---|
| `Y` | 書き込む (プログラムボードでは、ここでファイルを受け取る) |
| `N` | 捨てる |
| `T` | タイトルを変える |
| `E` | 本文を最初から入れ直す |
| `C` | 入力した文章を表示する |
| `Q` | 書きかけのまま抜ける (次に同じボードに書くときに続きから書ける) |

### プログラムボードとファイル転送

BMAKE でボードの種類を `program` にすると、1 件ごとにファイルを 1 つ付けられます。

- **上げる**: 書き込みの `Y` のあと、方式 (YMODEM / YMODEM-g / XMODEM-CRC / XMODEM-SUM) を選んで、端末ソフトから送ります。
  XMODEM のときはファイル名を入力します。受け取りに失敗したときは文章が残るので、もう一度 `Y` で送り直せます
- **下ろす**: 読んでいるときに `X` (XMODEM。ブロックを 1024 か 128 から選ぶ) か `Y` (YMODEM)
- **まとめて下ろす**: `S` でバッチリストに加え (16 件まで)、コマンド `BATCH` で YMODEM でまとめて送ります。
  BATCH の中では `Y` 送る / `O` 送ってから回線を切る / `N` 抜ける / `D` 外す / `L` 一覧 / `C` 空にする
- 中止は Ctrl-X を数回。telnet の BINARY オプションを使うので、0xFF や CR を含むファイルもそのまま送れます
- ファイルはデータベース (`files` 表) に入ります。1 つ 8MB まで

### SYSOP

| コマンド | 内容 |
|---|---|
| `BMAKE` / `BCHANGE` / `BKILL` / `BTITLE` | ボードの作成 / 設定の変更 (Enter は今の値のまま) / 削除 / タイトルの変更 |
| `BUSER` | CUG ボードのアクセス権 (a:読み書き r:読むだけ w:書くだけ n:なし) |
| `MAKEID` | 入会の申し込みに ID を発行する (入会の方式が「手作業」のとき) |
| `GULV` | 仮会員を正会員にする |
| `ULEVEL` / `UTIME` / `UPASS` | 会員のレベル / 持ち時間 / パスワード |
| `MCHANGE` | 会員の個人情報を変える |
| `IDKILL` / `IDSET` | ID の削除 / 状態フラグ |
| `MESEDIT` | ログイン画面などのメッセージ (0〜9) を変える |
| `SYSSET` | ネットワーク ID、レベル、持ち時間などの設定 |
| `SIGNUP` | 入会の方式 (自動 / 手作業 / オンラインでは受け付けない) |
| `AOFF` / `AON` | 新しいログインを禁止 / 許可 |
| `SECRET` / `SECOFF` | 極秘モード (LLIST と LOG に出ない) |
| `FILEM` | ファイルメンテナンス (削除したメッセージを消して番号を詰める) |
| `REPORT` | 稼働状況 |
| `STORE` | データを保存し直す |

`IDCOPY`、`UDLIST`、`UDEDIT`、`LINESET`、`SCSET` などはまだ用意していません。

## レベル

| レベル | 意味 |
|---|---|
| 0 | ゲスト |
| 30 | 仮会員 (SYSSET で変更可) |
| 50 | 一般会員 (SYSSET で変更可) |
| 80〜 | Sigop |
| 100〜 | SYSOP |

## MESEDIT のメッセージ

| 番号 | 表示する場面 |
|---|---|
| 0 | 接続したとき (ID を聞く前) |
| 1 | ログインしたとき (全員) |
| 2 | ログインしたとき (会員) |
| 3, 5 | ログインしたとき (ゲスト) |
| 4 | ログアウトするとき |

## 終了

SIGTERM / SIGINT (Ctrl-C) / SIGHUP を受けると、データを保存してから終了します。

## 持ち時間

残りが 60 秒になると「あと N 秒で切断します」と予告し、0 になると切断します (SYSOP は無制限)。
